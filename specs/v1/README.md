# Agent-Pay Specification v1

This directory will contain the first normative protocol specification.

Planned areas:

- Overview and terminology
- Payment Intent
- Spending Policy
- Decision model
- Approval model
- Payment execution lifecycle
- Transaction states
- Settlement
- Refunds
- Ledger events
- Error model
- Security requirements
- Interoperability requirements

No document in this directory is normative until explicitly marked as such.
