# Agent-Pay Protocol

The protocol defines interoperable financial-intent and financial-execution semantics without requiring one implementation or payment provider.

## Protocol boundary

Agent-Pay begins after an agent presents sufficient authority evidence from the Agentic Trust Foundation or another compatible authority system.

The protocol should standardize:

- Payment Intent semantics
- Spending constraints
- Financial decision outcomes
- Approval requirements
- Payment execution state
- Transaction lifecycle
- Settlement and refund events
- Financial audit events

Identity and general delegation semantics remain dependencies of the Trust Foundation protocol rather than being redefined here.
