# Problem Statement

Traditional payment systems assume a human or application directly controls a payment instrument. Agentic commerce introduces software that can discover offers, make decisions, and request transactions on behalf of people or organizations.

Giving an agent raw access to a wallet, card, bank credential, or unrestricted payment API creates excessive authority and makes policy enforcement, revocation, accountability, and audit difficult.

Agent-Pay addresses the financial-execution side of this problem by separating **intent** from **financial authority and execution**.
