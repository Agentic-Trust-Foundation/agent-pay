# Security

Security is a first-class protocol concern.

Initial threat areas:

- Unauthorized spending
- Agent impersonation
- Credential or token theft
- Replay of payment requests
- Delegation abuse
- Privilege escalation
- Compromised agent
- Malicious merchant
- Payment-instrument compromise
- Policy bypass
- Approval bypass
- Double spending or duplicate execution
- Settlement inconsistency
- Ledger tampering
- Sensitive financial-data leakage

The security model will distinguish authority failures from financial-control failures and define fail-closed behavior for ambiguous decisions.
